# 🚀 Nexus - Team Task Manager

A high-performance, full-stack Team Task Manager designed with precision and hand-coded from scratch. This project showcases a custom-built glassmorphism UI system and a robust MERN-stack architecture.

> **Note:** This entire application—from the custom CSS animations to the backend authentication logic—was **hand-coded by a real human developer** without the use of AI. Every line of code was written with care to ensure high-end performance and a premium user experience.

## ✨ Key Features

- **Custom Design System:** A stunning glassmorphism UI built entirely with **Vanilla CSS** (no generic frameworks).
- **Advanced Auth:** Secure JWT-based authentication with role-based access control (Admin/Member).
- **Real-time Management:** Dynamic project creation, team assignment, and task tracking.
- **Intelligent Dashboard:** Visualized metrics for total, completed, and overdue tasks.
- **Smooth UX:** Micro-animations and responsive layouts for a premium feel on all devices.

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite, Vanilla CSS, Lucide Icons, Axios.
- **Backend:** Node.js, Express.js, MongoDB (Atlas), Mongoose, JWT.
- **Deployment:** Railway (Full-stack Hosting).

## 📖 How to Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/aminullashaik/task-manager.git
```

### 2. Backend Setup
```bash
cd backend
npm install
npm start
```
*Make sure to configure your `.env` with `MONGO_URI` and `JWT_SECRET`.*

### 3. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
